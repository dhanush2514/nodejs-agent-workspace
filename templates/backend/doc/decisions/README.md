# Project decisions

No project architectural decisions have been approved merely by running the generator.
Use the [ADR template](../workflow/templates/adr.md) and confirm the actual approver.

| ID  | Decision | Status | Approver | Evidence |
| --- | -------- | ------ | -------- | -------- |

Use sequential IDs. Accepted decisions are superseded, not rewritten.
`standards-exceptions.json` starts empty; hash-bound exceptions require an accepted
project ADR, a confirmed approver and review evidence.
